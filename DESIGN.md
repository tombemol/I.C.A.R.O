# Overview

I.C.A.R.O. usa uma interface escura, direta e mobile-first. A tela deve parecer uma ferramenta de progressão pessoal, não um painel corporativo e nem uma coleção de cards gerados automaticamente.

# Colors

- Background principal: `#0a0a0b`
- Superfície elevada: `#111113`
- Superfície secundária: `#171719`
- Linha/divisor: `#2b2b2f`
- Texto principal: `#f5f3ef`
- Texto secundário: `#96969f`
- Ação/destaque: `#f0b74a`

O amarelo é reservado para ação, progresso e estado selecionado. Não pintar tudo de amarelo como se a interface tivesse descoberto marca-texto ontem.

# Typography

- Família: system UI / Inter quando disponível.
- Títulos têm contraste forte de tamanho e peso.
- Labels são pequenas, em caixa alta e com tracking leve.
- Textos longos devem ficar em largura confortável e com line-height generoso.

# Layout

- Mobile-first.
- Priorizar fluxo vertical e divisores em vez de caixas aninhadas.
- Uma ação principal por contexto.
- Espaçamento define agrupamento: itens relacionados ficam próximos; seções distintas respiram mais.

# Elevation & Depth

- Quase plana.
- Sombra apenas em elementos flutuantes, como a navegação inferior.
- Evitar cards dentro de cards.

# Shapes

- Cantos moderados: 10–18px conforme hierarquia.
- Inputs e botões têm altura mínima confortável para toque.
- Progressos lineares e circulares podem usar raio total.

# Components

## Botão primário
Fundo amarelo, texto escuro, peso alto. Apenas para a próxima ação mais importante.

## Botão secundário
Fundo transparente, borda discreta.

## Listas
Preferir divisores horizontais a um card por item.

## Formulários
Labels claras, ajuda curta, erro junto do campo. Campos agrupados pela tarefa, não pelo tipo técnico.

## Navegação
Barra inferior compacta com quatro destinos no máximo.

# Do's and Don'ts

- Fazer a hierarquia responder “o que importa agora?” em menos de dois segundos.
- Usar spacing, tipografia e divisores antes de criar mais uma caixa.
- Preservar contraste e foco visível.
- Não usar gradiente decorativo genérico.
- Não usar estatísticas soltas só para preencher espaço.
- Não misturar cinco estilos de botão.
